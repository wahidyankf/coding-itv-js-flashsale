# Reference

Facts to look up. The pages list what exists; they do not explain why.

## Directory Map

- [http-endpoints.md](http-endpoints.md) - the HTTP routes of `flash-be` and `flash-web`, with their responses.
- [contract.md](contract.md) - every export of `@flash/contract`: the route table, the schemas, the request and reply functions.
- [openapi.json](openapi.json) - the OpenAPI document, generated from the routes of `flash-be`.
- [test-layers-and-coverage.md](test-layers-and-coverage.md) - test layers, Nx targets, coverage floors, and hooks.
- [load-test.md](load-test.md) - the load test stack, profiles, limits and checks.
- [typekit.md](typekit.md) - every export of `@flash/typekit`: `Result` and `attempt`.
