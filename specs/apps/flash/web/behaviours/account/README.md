# Account

The login of a shopper on the sale page: sign up, log in, log out, and what the page does when the login ends.

## Features

- [login.feature](login.feature) - the form for a visitor who is not logged in, the words for each refusal, the cookie
  that keeps a shopper known, logging out, and the two ways a login ends (the short token alone, or the whole login).
