# Flash Sale Specifications

The specifications for the flash sale product, which has one API, one web app and one load test.

## Directory Map

- [c4/](c4/README.md) - the as-built C4 model of the whole product, from system context down to components.
- [be/](be/README.md) - the `flash-be` API: its behaviour scenarios and the test layers that bind them.
- [web/](web/README.md) - the `flash-web` app: its behaviour scenarios and the test layers that bind them.
- [load/](load/README.md) - the `flash-load` load test: its profiles, the limits a run must meet, and the checks that decide it.
