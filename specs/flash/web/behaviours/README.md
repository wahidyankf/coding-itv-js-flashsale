# flash-web Behaviours

The Gherkin corpus for the web app, grouped by business area.

## Directory Map

- [home/](home/README.md) - the home page and the backend status it shows.
- [sale/](sale/README.md) - the sale page: status, buying, and checking the outcome.
- [proxy/](proxy/README.md) - the web server routes that pass requests on to the API.
- [health/](health/README.md) - the web app's own liveness route.
- [config/](config/README.md) - how the web app finds the API.
